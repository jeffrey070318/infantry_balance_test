# 轮侧复合齿轮自主分析

## 已从 CAD 得到的事实

- `双联齿轮2A` 有 3 个装配实例，三根轴在轮轴周围等间隔分布，中心距均约 `17.10 mm`。
- 双联齿轮的两组齿形分别约为 `40T` 和 `10T`，模数 `0.6` 与文件名 `圆柱齿轮67×0.6A` 一致。
- 同轴齿圈/终级齿轮 `圆柱齿轮67×0.6A` 为 `67T`。
- 由 `67T` 齿圈与 `10T` 小行星轮的内啮合中心距 `20.1-3.0=17.1 mm`，以及 `40T` 大行星轮与太阳轮的外啮合中心距 `12.0+5.1=17.1 mm`，太阳轮齿数反推为 `17T`。
- `圆柱齿轮67×0.6A`、`120mm wA` 和轮侧上盖存在多组共轴安装孔；`3508A` 与中心支架存在多组安装/定位轴；中心支架与连腿连接座存在 6 条共轴安装孔。

## 传动候选

这是一套复合行星结构，齿数关系可写为：

```text
太阳轮 Ns = 17
大行星轮 Np1 = 40
小行星轮 Np2 = 10
齿圈 Nr = 67
```

如果保持架固定、齿圈/轮子为输出，则齿圈相对太阳轮的速度比为：

```text
omega_ring / omega_sun = -(Ns*Np2)/(Nr*Np1)
                     = -170/2680
                     = -0.06343
```

对应外置齿轮减速幅值约 `15.7647:1`，方向相反。

如果齿圈固定、保持架为输出，仍必须使用上面的复合行星关系，不能套用简单行星排的 `Ns/(Ns+Nr)` 公式。令

```text
k = -(Ns*Np2)/(Nr*Np1) = -170/2680
```

则齿圈固定 (`omega_ring = 0`) 时：

```text
omega_carrier / omega_sun = k/(k-1) = 0.05965
```

对应减速幅值约 `16.7647:1`，方向与太阳轮相同。这是另一种“齿圈固定、保持架输出”的候选，不能与第一种 `15.7647:1` 候选混用。

## 尚未强行确定的部分

STEP 没有表达“哪个零件在机架上固定、哪个零件通过轴承相对旋转”的运动副约束。当前装配关系更支持“中心支架/电机定子固定，齿圈/轮侧外壳输出”的第一种候选，但仍需在 SolidWorks 中确认保持架是否锁在中心支架上，以及 M3508 使用的是 P19 减速输出还是去掉内部减速后的电机转子轴。

你们的实际使用方式是 M3508 的 `3591/187` 内部减速后再接 CAD 外置减速器，因此候选总减速幅值应相乘。第一种候选的总幅值约为 `19.2032*15.7647=302.72:1`，轮端额定转速约 `469/15.7647=29.75 rpm`；第二种候选的总幅值约为 `19.2032*16.7647=322.0:1`。这个低速高扭矩结果本身并不说明型号矛盾，只说明底盘采用了两级减速。最终仍需用固定件、输出件和实测轮速确认候选方向与效率。

## 六维仿真的当前选择

在机械配合尚未最终确认前，六维仿真先采用第一种候选：`保持架固定、齿圈/轮子输出`。代码中的外置传动比取 `-15.7647`，负号表示太阳轮与齿圈反向；整车前进方向、编码器符号和传动效率仍单独保留为待标定量。以后若装配检查推翻该假设，只替换传动拓扑参数，不改六维动力学状态定义。
