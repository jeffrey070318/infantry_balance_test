# 真实六维动力学参数采集模板

本文件原先按完整多刚体质量属性展开。复核哈工程、SPR、上交/HKU和Webots开源后，确认逐连杆参数不是当前六维模型的前置条件；当前只采集下表中的总成级等效参数，后面的逐刚体表仅保留给未来高保真验证。

## 当前六维必需参数

| 参数 | 含义 | 当前来源 |
|---|---|---|
| `R` | 有效轮半径 | CAD为0.06 m，后续用滚动距离校准 |
| `L0` | 轮心到髋轴的等效腿长 | 已由CAD正运动学实时计算 |
| `mw` | 单侧轮及随轮平移部分的等效质量 | 待称重/总成质量属性 |
| `Iw` | 单侧轮侧等效转动惯量 | 第一版几何近似，后续辨识 |
| `mp` | 单条腿等效质量 | 待称重/总成质量属性 |
| `Ip` | 单条腿绕等效质心的俯仰惯量 | 第一版几何近似，后续按腿长修正 |
| `M` | 机体等效质量 | 待称重/总成质量属性 |
| `IM` | 机体俯仰惯量 | 第一版包络尺寸近似，后续辨识 |
| `l` | 机体质心到髋轴距离 | 待总成质心或悬挂测量 |

第一版本队六维允许取 `L=LM=L0/2`。这与哈工程、平步和SPR六维开源的处理一致，后续取得腿部等效质心后再修正。

## 高保真模型备用参数

## 坐标和单位

- CAD 关节轴为 `X` 轴，机构平面为 `Y-Z` 平面。
- 质量用 `kg`，质心坐标用 `m`，转动惯量用 `kg*m^2`。
- SolidWorks 导出的 `mm` 和 `kg*mm^2` 必须先换算，再进入 MATLAB。

## 还必须单独确认

1. 气弹簧的安装点、自由长度、刚度或力-长度曲线、预紧力。
2. 每个关节的转动惯量是否已经包含电机转子、减速器和链轮。
3. 左右腿是否可以镜像使用同一组参数。
4. 轮端转动惯量是否包含轮胎和轮毂，轮边减速箱效率取实测还是分级估计。
5. SolidWorks 质量属性使用的材料密度是否与实物一致。

## 接入规则

质量属性完整前，继续使用 `heu_reference_parameters` 只做控制算法和数值流程验证；不得把占位质量参数标记为本队动力学参数。完整后先做静态重力平衡和小扰动线性化，再做轨迹、饱和与执行器约束验证。
